# LumiROM Releases

This directory contains archived LumiROM releases for the Samsung Galaxy A32.

## Purpose

The goal of this archive is to preserve publicly released LumiROM builds and associated information after the original project resources became unavailable.

## Known Releases

| Version | Status | Notes |
|----------|---------|---------|
| v8.6.2 Stable | Archived | Latest known public release |

## Release Contents

Each release directory may contain:

- ROM ZIP
- SHA256 checksums
- Screenshots
- Release notes
- Installation instructions
- Known issues
- Download mirrors

## Installation Notice

Always use the vendor package recommended for the release you are installing.

Using an incompatible vendor package may cause:

- Bootloops
- Missing hardware functionality
- Camera issues
- Stability problems

## Preservation Status

Community members are encouraged to contribute:

- Missing ROM releases
- Checksums
- Screenshots
- Changelogs
- Original release notes
- Download mirrors

Please open an Issue or Pull Request if you possess files not currently archived.
